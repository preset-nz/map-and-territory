## Using it

A campaign is the file you save: one `.campaign` document holding every map for a game, plus the palettes they draw from. Each file has exactly one, and you can't delete or duplicate it.

Name it after the game or the setting, and use the description for whatever you want to find again later. The palette set here is the one every map falls back on, so choosing a palette for the campaign gives all its maps the same look. A map can still pick its own.
